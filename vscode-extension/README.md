# MaduraLang VS Code Extension

Ekstensi resmi Visual Studio Code untuk bahasa pemrograman **MaduraLang** (`.mdr`).

## Fitur
- Pewarnaan sintaks (*Syntax Highlighting*) penuh untuk seluruh kosa kata MaduraLang v2.0 (`sango`, `paggun`, `bhangsa`, `nyambi`, `antose`, `lamon`, `poter`, `kocaaghi`, dll.).
- Pencocokan kurung (*Bracket Matching*) dan penutup otomatis (*Auto-closing pairs*).
- Komentar otomatis (`//` dan `/* */`).
